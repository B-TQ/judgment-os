# Roadmap

## v0.3 implemented

- [x] Preserve original v0.2 in legacy/v0.2 and keep the core optional Skill unchanged.
- [x] Shared binding task requirements and four conditions including minimal baseline.
- [x] Prompt simulation and staged native Codex CLI adapter with explicit dry-run/live controls.
- [x] Deterministic validators for eligible text properties.
- [x] Output provenance, run states and input/output integrity checks.
- [x] Re-keyed allowlisted exports, limited redaction and independent-reviewer imports.
- [x] Multi-judge aggregation, failure/missing disclosure, paired analysis and conditional case-cluster intervals.
- [x] Tests, offline demo, bilingual documentation, CI matrix and source-only packaging.

## Verification still required

- [x] Limited authentic live Codex completions and probe-only Skill-body access (v0.4).
- [x] Three independently tasked AI-authored cases, four native conditions and a blind model-review pilot (v0.4).
- [x] Immutable source/evidence checkpoints and verification (v0.4).
- [ ] General behavioral efficacy and consistent original-Skill use across tasks.
- [ ] Dedicated clean environment to quantify ambient Skill/instruction confounding.
- [ ] Genuine independent reviewer data and reproduced efficacy reports.

- [ ] Multi-model/domain replication and statistical power planning.

## Later proposals

- [ ] Rate-limited paid evaluator adapters with explicit budgets (not needed for current offline workflow).
- [ ] Verified cross-host integration, including Claude Code.
- [ ] Human-verified provenance profiles and host-integrated resolution (not a keyword classifier).
- [ ] Separate reviewed public research-data exporter and signed provenance.

No performance or compatibility claim follows from a checked implementation item.

v0.4 observed no quality advantage of the full Meta-Skill over a one-sentence reminder on its three cases. The next research priority is evaluator calibration, harder independently selected practical tasks and cleaner runtime context, rather than adding prompt complexity or repeating this ceiling-limited pilot until a win appears. Independent human assessment remains absent.
