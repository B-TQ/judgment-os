# Judgment OS v0.7 — Optional Skill guidance and offline evaluation

**[Download source ZIP](https://github.com/B-TQ/judgment-os/releases/download/v0.7/Judgment-OS-v0.7-source.zip)** · [中文](#中文) · [English guide](https://github.com/B-TQ/judgment-os/blob/main/docs/README.md)

## Start in a minute

Install Python 3.11+, download and extract the ZIP, then:

- **Windows:** double-click `TRY_DEMO.cmd`.
- **Any supported OS:** from the extracted folder, run `python scripts/try_demo.py`.

Both run the same offline doctor, tutorial and correct-answer check. No pip install, account, API key or model call. The tutorial prepares eight empty slots and checks authored fixtures; it creates no model answers or ratings.

## Choose your path

**Try Judgment Preserver:** an optional prompt-level Skill for adapting genuinely optional defaults within binding requirements. [Preview, install, invoke and safely remove](https://github.com/B-TQ/judgment-os/blob/main/docs/USAGE_DECISION.md#english). It does not add authority or guarantee better reasoning.

**Evaluate your Skills:** freeze common requirements across A task-only, B domain Skill, C B + full core, D B + one-sentence reminder; collect genuine answers, check declared properties, re-key review packets and keep failed/missing runs and disagreements visible. [Study quickstart](https://github.com/B-TQ/judgment-os/blob/main/docs/QUICKSTART.md).

## What v0.7 ships

- Unified Python CLI for prerequisites, an eight-slot offline tutorial, one-answer checks, study collection, explicit review phases and reporting.
- Managed project-local Skill install/removal: preview first, refuse existing files, preserve changed or extended trees.
- Deterministic JSON/CSV/text/length checks, frozen hashes, source allowlist/checksums and Windows/Linux Python 3.11/3.14 CI.
- English/Chinese documentation, original diagrams, labeled software demo and manual community drafts.

## Evidence and boundaries

The recorded eight-case follow-up remains **C–D: 1 win / 7 ties**. The sole win came from D exceeding a word limit by one word. The adoption threshold was not met; the full Skill stays optional. Initial review-context leakage and the corrective projectless phase are both disclosed. These are model-only, small-sample results, not human utility validation or a general benefit.

Raw private studies are not attached, so complete historical model judgments cannot be recomputed from public source alone. Claude Code native integration and cross-model efficacy are unverified. [Evidence](https://github.com/B-TQ/judgment-os/blob/main/docs/launch/EVIDENCE.md).
