# v0.7 release candidate

This document preserves the pre-launch local verification snapshot. For current public repository, CI and Release status, see [LAUNCH_REPORT.md](../LAUNCH_REPORT.md). / 本文保留发布前本地验收快照，最新状态以最终发布报告为准。

This version is a usable source-checkout evaluation toolkit with an optional experimental Skill. It does not establish new model-performance benefits and does not add live research runs.

## Delivered

- One public CLI for offline prerequisites/tutorial, one-answer checks, study collection, review/report phases and source packaging. No pip dependency or API key is needed for offline use.
- Managed project-local Skill install/uninstall with dry-run, existing-file refusal, and preservation of modified or extended user trees.
- Bilingual README, labeled fixtures, quickstart/command guides, contributor/conduct/security policies, GitHub issue/PR templates and offline workflows.
- Historical handoff text moved under docs/history/; original v0.2 source and v0.6 evidence remain available. The core body is unchanged.
- CI actions pinned to commits resolved from official releases on 2026-10-27. The configured scope is current GitHub-hosted Windows/Linux runners.

## Local validation

Python 3.14.6 on Windows: 68 tests completed in 14.970 seconds, **67 passed and 1 skipped**. The skipped test needs Windows symlink privileges unavailable on this machine. A separate real Windows directory-junction probe passed: installation was refused and the external marker was preserved, then only the verified junction was removed.

The eight-slot public tutorial, larger 64-slot-per-mode smoke test and strict Skill metadata audit passed, all with zero model calls and no invented answers/ratings. Source/checksum, clean Git checkout and immutable-backup checks are performed at release finalization; their records accompany the local delivery.
