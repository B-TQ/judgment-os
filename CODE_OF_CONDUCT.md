# Community conduct

Treat participants with respect. Discuss ideas and evidence without personal attacks. Harassment, discriminatory abuse, threats, doxxing, unsolicited sexual content and publishing private information are not acceptable.

Disagree with claims by explaining the task, evidence and limitations. Do not pressure contributors to disclose private model outputs, account details or personal circumstances.

Maintainers may edit or remove harmful content, limit participation, or block accounts to protect the community. They should apply these rules consistently and avoid retaliation against good-faith reports.

To report a concern, contact the repository maintainer through an available private contact option on their GitHub profile or a private repository reporting channel when enabled. If no private route is available, open an issue asking for a contact channel without including sensitive details. This project does not currently promise a response time or dedicated incident team.

These rules apply in project discussions, issues, pull requests and other official project spaces.
